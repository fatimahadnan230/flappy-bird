# 🐣 Flappy Bird ☁️

A charming, relaxing, yet challenging arcade game inspired by classic Flappy Bird, redesigned with a cozy pastel sky theme, fluffy clouds, and a cute flying chick. Built for the Game Development Society!

## 🎮 Features
* **Smooth Physics Engine:** Custom gravity, velocity, and jump mechanics built directly into HTML5 Canvas.
* **Pastel Aesthetic:** Soft pink, mint, lilac, and yellow color palettes with customized rounded obstacle pipes.
* **High Score Tracking:** Automatically saves your personal best score using browser `localStorage`.
* **Sound Effects:** Custom synthesized retro audio cues for flapping, scoring, and crashes using the Web Audio API.

## 🚀 Built With
* **HTML5 Canvas & JavaScript**
* **Tailwind CSS**

## 🕹️ How to Play
* Press the **Spacebar** or **Click/Tap** the game screen to make the cute bird flap upward.
* Navigate safely through the gaps between the pastel pipes without hitting the ground or obstacles.
* Score a point for every pipe you successfully pass!
